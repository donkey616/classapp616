# 香港智慧城市地圖

一幅可互動的香港地圖。底圖用 [OpenFreeMap](https://openfreemap.org/) 的公開 Positron 樣式。地圖上有十條港鐵重鐵和運輸署交通快拍點。

- 點一個車站，查看該站所屬路綫即將到站的列車，包括目的地、月台和大約幾分鐘後到達。
- 點一個快拍點，查看該處最新照片。縮小時快拍點會合成一組。
- 沒有班次、連不上服務，或照片載入失敗時，畫面會直接說明。

輕鐵不在今次使用的到站接口裡，所以沒有畫上。

## 資料怎樣配合

| 畫面 | 來源 | 何時讀取 |
| --- | --- | --- |
| 底圖 | OpenFreeMap Positron | 開啟地圖時由瀏覽器直接讀取，不用 API 金鑰 |
| 車站位置 | 地政總署港鐵站範圍的中心 | 建置時收錄，共 98 個站 |
| 路綫和站名 | 港鐵「路綫及車站」公開檔 | 建置時收錄，並按行車順序連線 |
| 到站班次 | 資料一線通港鐵實時列車服務 | 點選車站時才查詢 |
| 快拍位置和照片 | 運輸署交通情況快拍圖像 | 開啟頁面時讀位置，點選時顯示 JPEG |

馬場站不在路綫檔裡，但在到站接口和地政總署車站範圍裡，所以有畫上，並接在火炭與大學之間。路綫檔的「茘」和地政總署的「荔」會當成同一站。

路線顏色是方便閱讀的慣用色，不是到站接口的欄位。底圖原有的鐵路綫會關掉，避免和港鐵路綫疊在一起。

## 本地預覽

需要 Node.js 22.6.0 或以上。

```bash
npm install
npm run dev
```

開發伺服器在連接埠 **4738**。瀏覽器打開後會看到香港，可以拖動和縮放。

重新向官方來源整理車站和路綫：

```bash
npm run data
npm run verify
```

## 正式版

正式版打算放到 Cloudflare Workers 免費方案，使用帳戶自帶的 `workers.dev` 網址。`wrangler.jsonc` 只發布 `dist` 裡的靜態檔案，沒有開啟會計入每日請求的 Worker 程式，也沒有使用 KV、R2 或自訂網域。

按 Cloudflare 現時的說明，靜態檔案請求免費，儲存靜態檔案不另收費。預計費用是 **0 美元**。這份設定尚未部署。

驗收之後才執行：

```bash
npm run build
npx wrangler deploy
```

部署前需要自己的 Cloudflare 帳戶登入。不要把 `run_worker_first` 設為 true，否則靜態頁面也會計入免費方案每日 10 萬次的動態請求。

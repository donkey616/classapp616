# 香港智慧城市地圖

一幅可互動的香港地圖。底圖用 [OpenFreeMap](https://openfreemap.org/) 的公開 Positron 樣式。地圖上有十條港鐵重鐵和運輸署交通快拍點。

- 點一個車站，查看該站所屬路綫即將到站的列車，包括目的地、月台和大約幾分鐘後到達。
- 點一個快拍點，查看該處最新照片。縮小時快拍點會合成一組。
- 沒有班次、連不上服務，或照片載入失敗時，畫面會直接說明。

輕鐵不在今次使用的到站接口裡，所以沒有畫上。

## 資料怎樣配合

| 畫面 | 來源 | 何時讀取 |
| --- | --- | --- |
| 底圖 | OpenFreeMap Positron | 開啟地圖時由瀏覽器直接讀取，不用 API 金鑰 |
| 車站位置 | 地政總署港鐵站範圍的中心 | 建置時收錄，共 98 個站 |
| 路綫和站名 | 港鐵「路綫及車站」公開檔 | 建置時收錄 |
| 路線形狀 | OpenStreetMap 港鐵路軌 | 建置時收錄，沿實際路軌彎行 |
| 到站班次 | 資料一線通港鐵實時列車服務 | 伺服器大約每 60 秒查詢整張網絡一次，所有訪客共用。瀏覽器不會直接呼叫港鐵 |
| 行駛中列車 | 同一份快取，沿路軌推算 | 畫面大約每 15 秒查看快取是否過期。不是 GPS |
| 快拍位置和照片 | 運輸署交通情況快拍圖像 | 開啟頁面時讀位置，點選時顯示 JPEG |

馬場站不在路綫檔裡，但在到站接口和地政總署車站範圍裡，所以有畫上。路線彎度跟 OpenStreetMap 的路軌，包括落馬洲、康城和馬場支線。路綫檔的「茘」和地政總署的「荔」會當成同一站。

路線顏色是方便閱讀的慣用色，不是到站接口的欄位。底圖原有的鐵路綫會關掉，避免和港鐵路綫疊在一起。

## 本地預覽

需要 Node.js 22.6.0 或以上。

```bash
npm install
npm run dev
```

開發伺服器在連接埠 **4738**。瀏覽器打開後會看到香港，可以拖動和縮放。

到站班次由 `/api/schedules` 提供。快取未過期時，這條路徑不會再向港鐵發出請求。港鐵回應太頻密時，伺服器會暫停約一分鐘，並繼續使用上一份成功的班次。本地沒有資料庫時，快取放在行程內的暫存資料庫。正式環境使用應用程式自己的 Postgres，所以不同實例也共用同一份結果。

重新向官方來源整理車站和路綫：

```bash
npm run data
npm run verify
```

## 建置

```bash
npm run build
npm start
```

`npm start` 同樣使用連接埠 **4738**。

## Cloudflare Workers

需要已登入的 Cloudflare 帳戶。第一次在自己的電腦執行 `npx wrangler login`。

```bash
npm run deploy:cf
```

Workers 免費方案每次最多大約 50 個對外請求，所以整張網絡會分成幾批收集，收集完成後同樣共用約 60 秒。Cursor 上的正式版仍用自己的 Postgres，不受這次部署影響。
